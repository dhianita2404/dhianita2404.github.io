# Tech stack

- **HTML + CSS + sedikit JavaScript.** Tanpa framework dan tanpa build step, jadi file bisa langsung dibuka di browser. Mockup awal memakai Tailwind CDN; versi ini diubah ke CSS biasa supaya ringan dan semua warna ada di satu tempat (`style.css`).
- **Google Fonts** untuk Inter.
- **Git + GitHub** untuk menyimpan riwayat perubahan.
- **GitHub Pages** untuk hosting gratis di alamat `username.github.io`. Custom domain bisa ditambahkan nanti.
- **Cara menjalankan di laptop:** buka `index.html` di Chrome, atau jalankan `npx serve .` lalu buka alamat yang muncul.

Alasan: portofolio jarang berubah, tidak butuh database atau login. Website statis paling murah, cepat, dan aman.
